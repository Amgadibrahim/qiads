# Qi Ads · landing page prototype

Interactive light prototype of the Qi Ads advertiser page (qi-ads.com), shared for internal review.

- Live page: https://amgadibrahim.github.io/qiads/
- Audience numbers, campaign results, advertiser logos and sample ads are illustrative placeholders until real data is approved.
- One self-contained file: the fonts (Alexandria and IBM Plex Sans Arabic, SIL Open Font License) and the GSAP motion library are embedded, so the page has no outside dependencies.
